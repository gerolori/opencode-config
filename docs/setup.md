# Setup

## Prerequisites

- OpenCode 1.19.5 (runtime).
- Bun 1.3.9.
- Node 25.6.1.
- `uv` / `uvx` for the DuckDuckGo MCP server.
- `sqz-mcp.exe` on `PATH` for the sqz MCP server (current Windows selection).
- `br` / `bv` on `PATH` only if Beads tracking is used.

Runtime and SDK are pinned to the same version. Do not major-upgrade one without the
other.

## Install

From the config directory:

```text
bun install
bun run typecheck
bun test
bun run preflight -- --config
```

`bun.lock` is authoritative. `package-lock.json` is ignored and may be regenerated by
the runtime plugin installer.

## Config layering

1. `opencode.jsonc` — tracked base.
2. `opencode.host.example.jsonc` — tracked portable overlay using
   `SEMBLE_MCP_DIR` / `EBAY_MCP_DIR`.
3. `opencode.private.local.json` — ignored host overlay for this machine. It is not
   loaded automatically as of this writing. Load it explicitly, for example:

```powershell
$env:OPENCODE_CONFIG = "C:\Users\hermes\.config\opencode\opencode.private.local.json"
opencode
```

or point `OPENCODE_CONFIG` at a host overlay generated from the example.

Verify the merge without printing secrets:

```text
opencode debug config
```

Check that the expected MCP entries are `enabled` and that no unexpected credential is
present in output.

## Host overlays

Use forward-slash paths in environment values on Windows:

```powershell
$env:SEMBLE_MCP_DIR = "C:/Users/hermes/mcp-servers/semble"
$env:EBAY_MCP_DIR = "C:/Users/hermes/mcp-servers/ebay"
```

The base config keeps Semble and eBay disabled. The preferred final behavior is
HOME-derived auto-enable or a documented local override; do not commit a machine path.

## Keys

Never paste a literal key into a command, file, or transcript. Use a masked prompt so
it does not enter shell history.

PowerShell:

```powershell
$secure = Read-Host -AsSecureString "EXA_API_KEY"
$env:EXA_API_KEY = [Runtime.InteropServices.Marshal]::PtrToStringBSTR(
  [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure))
```

```powershell
$secure = Read-Host -AsSecureString "TINYFISH_API_KEY"
$env:TINYFISH_API_KEY = [Runtime.InteropServices.Marshal]::PtrToStringBSTR(
  [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure))
```

Bash:

```bash
read -rs EXA_API_KEY && export EXA_API_KEY
read -rs TINYFISH_API_KEY && export TINYFISH_API_KEY
```

Restart OpenCode from the same process so plugins and MCP clients inherit the
variables. Do not create tested/tracked `.env` files, and do not print or copy auth
stores.

Missing keys must not block offline implementation. Report the exact manual command
instead.

## Auto-update

`autoupdate` is `false`. Upgrade deliberately:

```text
opencode upgrade <version>
```

Then update `package.json`, reinstall, and run the verification commands. Do not claim
a runtime/SDK match until `preflight` confirms it.

## Windows notes

- `sqz` MCP currently uses the executable name `sqz-mcp.exe`; this is a
  platform-specific choice still owned by integration.
- DuckDuckGo MCP uses `uvx --python 3.11 duckduckgo-mcp-server`.
- Semble requires a preserved path on Windows; use the host overlay until an
  automatic HOME-derived path is implemented.

## Portability

The canonical path is `~/.config/opencode` with remote
`https://github.com/gerolori/opencode-config.git`. Never clone over an existing
directory. See `docs/portability.md`.
